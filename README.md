# 🦷 Tanpure Dental Clinic Website

A modern, responsive website developed for Tanpure Dental Clinic to showcase services, doctor information, contact details, and improve online presence.

---






## 🌐 Live Demo
tanpuredental.netlify.app

---

## 📌 Project Overview

This website is designed to provide:

- Clinic information
- Services offered
- Appointment/contact details
- Responsive mobile-friendly layout
- Clean and professional UI

The goal was to create a simple, fast-loading, SEO-friendly website for a local dental clinic.

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Responsive Design (Mobile-first approach)

---

## ✨ Features

- Responsive layout (mobile + desktop)
- Hero section with clinic branding
- Services section
- About section
- Contact form
- Google Maps integration
- Clean UI with modern design
